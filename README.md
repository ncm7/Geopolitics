
# LLM

Neeraj's personal geopolitics and political-philosophy system.

A daily brief lands at 6:00 AM CT. Every event it carries is tied to a concept,
and every concept gets filed here so the vocabulary compounds instead of evaporating.

## Structure

```
LLM/
├── 00-CHARTER.md     The operating rules. Read this to understand how the system thinks.
├── briefs/           One file per morning. briefs/2026/2026-09-15.md
├── threads/          Live situations tracked over time. Updated, not appended.
├── concepts/         The ledger. One file per concept, added the day it first earned its place.
├── reading/          Books, essays, primary texts — with notes.
└── notes/            Your own thinking. Nothing writes here but you.
```

## How to use it

- **Morning**: read the brief. Five minutes.
- **When something sticks**: open the concept file it points to. Ten minutes.
- **When you disagree**: write it in `notes/`. Disagreement is the point.
- **Ask anything**: the concepts and threads are context. Say "explain hegemonic stability
  theory against what's happening in Hormuz" and the answer will use what's in these folders.

## Focus areas

South Asia / India · US politics and foreign policy · China, Russia, great-power rivalry ·
Middle East, Africa, Latin America

## Learning mode

News-driven, no syllabus. Concepts arrive when events raise them. The concept ledger is
the curriculum, written backwards — you will end up with a political education shaped by
what the world actually did while you were watching it.
